Academic Student Tracking and Analytics System

Project Overview

The Academic Student Tracking and Analytics System is an independent project developed in collaboration with an academic program director at Tecnológico de Monterrey.

The project aims to make academic student follow-up more efficient by centralizing relevant student information, organizing academic data in a SQL database, and providing a dashboard that allows academic directors and their teams to access and analyze student information more easily.

Problem

Academic program directors need to monitor and follow up with students who may require additional academic support. According to the academic program director involved in this project, approximately 10% of students are irregular, but this group can account for more than 90% of the time dedicated to student follow-up.

This creates an operational challenge: although the group requiring intensive follow-up is relatively small, identifying, organizing, and reviewing the necessary information can require a disproportionate amount of time.

Objective

The main objective of this project is to develop a data-driven system that helps academic directors:

Centralize relevant student information.

Organize and store academic data in a SQL database.

Access student information more efficiently.

Visualize relevant academic information through a dashboard.

Facilitate the identification and follow-up of students who may require additional support.

Reduce the time required to manually search for and consolidate student information.

Stakeholder Collaboration

This project is being developed in direct collaboration with an academic program director.

The development process involves translating academic follow-up needs into technical and data requirements, with the goal of creating a solution that is useful in an actual academic environment rather than only as an academic exercise.

Expected Impact

The system is intended to improve the efficiency of academic follow-up by providing a centralized source of information and reducing the time required to locate, organize, and review student data.

The dashboard is designed to help academic directors identify relevant student information more quickly and support more informed follow-up decisions.
